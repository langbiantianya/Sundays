# dialect-postgresql — PostgreSQL 方言插件

idb_engine 的 **PostgreSQL 方言实现**，以 SPI 插件形式提供。

> **当前版本**：v2.9
>
> 架构与 SPI 接口定义见 [`api/README.md`](../api/README.md)。

| 属性 | 取值 |
|---|---|

| `displayName` | `"PostgreSQL"` |

## 连接约定

`buildJdbcUrl(host, port, database)` 返回 `jdbc:postgresql://$host:$port/$database`（附加 PG SSL 参数可经 `ConnectionConfig.properties` 注入）。

**流式查询配置**：必须**临时关闭 `autoCommit`** 启用服务端游标 —— PG 不支持 `Statement.setFetchSize` 触发服务端游标，只能依靠事务内的 cursor 机制。引擎在 `configureConnectionForStreaming` 中保存原状态，在 `restoreConnectionAfterStreaming` 中恢复。

## 方言特性

| 特性 | 实现 |
|---|---|
| **Schema 导航** | `pg_database WHERE NOT datistemplate`（database）+ `pg_namespace WHERE nspname NOT LIKE 'pg_%' AND nspname != 'information_schema'`（schema） |
| **search_path** | `SET search_path TO <schema>`（handler 自动注入 SQL 执行前） |
| **TABLE CREATE** | 支持 `COMMENT ON TABLE`（从 `options["comment"]` 读取） |
| **自增主键** | `INT` → `SERIAL`，`BIGINT` → `BIGSERIAL`；非 INT 类型走 `GENERATED BY DEFAULT AS IDENTITY` |
| **MODIFY COLUMN** | `ALTER TABLE ALTER COLUMN`（类型 / nullable / default 改写完整支持） |
| **GET_DDL** | 从 `information_schema` + `pg_catalog` 重建（含主键 / UNIQUE / CHECK 约束 + 索引） |
| **Routines** | `pg_proc` + `pg_namespace` + `information_schema.PARAMETERS`（FUNCTION / PROCEDURE / TRIGGER 全实现） |
| **Users / Privileges** | `pg_roles` + `information_schema.role_table_grants`（含 schema / table / privilege 三元组聚合） |
| **Triggers** | `pg_trigger` + `information_schema.triggers` + `pg_get_triggerdef` |

### SQL 危险关键词（方言层 `validateSqlFragment`）

通用集合 + PG 额外禁止 `COPY` / `DO`；ORDER BY 标识符允许双引号 `"col"`。

---

## 已知约束

- **DDL 事务**：PG 是少数支持 DDL 事务的关系型数据库之一，所有 CREATE / ALTER / DROP 可回滚
- **Schema 必传**：执行 SQL 时若想无前缀表名正确解析，必须传 `schema` 字段
- **Trigger 元数据**：`pg_get_triggerdef()` 在 PG 14+ 输出格式有差异，需解析容错

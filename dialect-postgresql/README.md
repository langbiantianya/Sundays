# dialect-postgresql — PostgreSQL 方言插件

idb_engine 的 **PostgreSQL 方言实现**，以 SPI 插件形式提供。

SPI 接口定义见 [`api/README.md`](../api/README.md)，引擎如何消费方言见
[`engine/README.md`](../engine/README.md)。

## 元数据

| 属性 | 取值 |
|---|---|
| `driverName` / `displayName` | `"Postgresql"` / `"PostgreSQL"` |
| `jdbcDriverClassName` | `"org.postgresql.Driver"` |
| `connectionType` / `defaultPort` | `CLIENT_SERVER` / `5432` |
| `jdbcUrlExample` | `jdbc:postgresql://127.0.0.1:5432/mydb` |
| `capabilities` | `USERS, PRIVILEGES, ROUTINES, VIEWS, INDEXES, FOREIGN_KEYS, TRIGGERS, CROSS_DATABASE, MULTI_SCHEMA, EXPORT, DDL_TRANSACTION` |

**全能力方言**：5 个方言里 capability 最多的 —— 多 schema + 跨 database + 用户/权限 +
例程 + 触发器 + 导出 + DDL 事务。

## 实现要点

**连接与流式查询** —— [`PostgreSQLDialect.kt`](./src/main/kotlin/com/langbiantianya/dialect/PostgreSQLDialect.kt)
的类级 KDoc 记了四条约束：

- `buildJdbcUrl` 返回 `jdbc:postgresql://$host:$port/$database`；SSL 参数经
  `ConnectionConfig.properties` 注入
- **流式查询必须临时关掉 `autoCommit`** —— PG 不认 MySQL 那条
  `setFetchSize(Integer.MIN_VALUE)` 服务端游标约定，只能靠事务内 cursor。
  `configureConnectionForStreaming` 保存原状态、`restoreConnectionAfterStreaming` 恢复，
  **成对出现**
- **`DDL_TRANSACTION` 是硬支持**（PG 是少数支持 DDL 事务的关系库之一），
  与 MySQL 的「软支持」相对
- 执行 SQL 想用无前缀表名，**必须传 `schema` 字段** —— 引擎会注入 `SET search_path TO <schema>`；
  另有 `pg_get_triggerdef()` 在 PG 14+ 的输出差异需解析容错

**方言特性**：schema 导航用 `pg_database`（database）+ `pg_namespace`（schema，过滤 `pg_%`）；
`CREATE TABLE` 支持 `COMMENT ON`；自增主键 `INT`→`SERIAL` / `BIGINT`→`BIGSERIAL`，
其余走 `GENERATED BY DEFAULT AS IDENTITY`；`GET_DDL` 从 `information_schema` + `pg_catalog`
重建；Routines 走 `pg_proc` + `pg_namespace` + `PARAMETERS`；Users/Privileges 走 `pg_roles`
+ `role_table_grants`；Triggers 走 `pg_trigger` + `pg_get_triggerdef`。

`validateSqlFragment` 在通用集合外额外禁 `COPY` / `DO`（会绕过事务与权限路径），
ORDER BY 标识符允许双引号包裹。

## 模块结构

```
dialect-postgresql/
├── build.gradle.kts          # 依赖 :api + kotlinx-coroutines + slf4j
└── src/main/kotlin/com/langbiantianya/dialect/
    └── PostgreSQLDialect.kt  # 单文件实现，5 个方言里最大的一个
```

无单元测试 —— PG 的端到端覆盖在 `engine/src/test/kotlin/integration/`。

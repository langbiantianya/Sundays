数据分析模式

一个独立于「连接管理 → 数据库浏览」的顶层模式：负责数据分析与报表制作，远程数据源恒为只读； 连接管理器与设置页直接复用现有实现。

  • 工作台完全独立：不共用 sheet、不共用浏览状态机。
  • 连接与设置复用：同一份 connection.json、同一个连接管理器、同一个设置页； 两个模式按能力位各取所需（可浏览 / 可分析）。
  • 远程数据源恒为只读，且是方言级：Hive / Impala 在引擎里根本没有写入路径， 从哪个模式进来都写不了。
  • 计算引擎默认 DuckDB（本地嵌入式分析引擎），可切换 Hive / Impala。
  • 目标：数据分析 → 制作 Excel 报表；后续迭代接入 AI 做智能分析。

未来主屏布局：左侧数据源树 + 右侧 SQL 编辑器与结果表，结果支持直接进入报表设计器。
